## Integration

Use responsive `srcset` and an accurate `sizes` value. Declare image width and height, set high fetch priority only on the visible hero, and lazy-load below-the-fold images. The hero source is 3:2. The explorer should preserve this ratio so its hotspots refer to the same building details at every width.

The homepage now uses six distinct photographs for the hero, three product cards, explorer and inspiration band. The explorer uses the full 3:2 `real-veranda` photograph, with window trim at 27% / 66%, porch fascia at 50% / 52%, and the right corner at 85% / 62%.

Describe these as possible architectural applications. The image does not establish that the depicted trim is PVC or supplied by Novex.
